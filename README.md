## 2. Запуск локально

### Требования
- **Node.js** версии 16 или выше
- **npm** (менеджер пакетов)

### Пошаговая инструкция

**1. Установите Node.js**
Скачайте с [nodejs.org](https://nodejs.org) (LTS версию).

**2. Откройте терминал** и перейдите в папку проекта:
```bash
cd path/to/it-moscow-voting
```

**3. Установите зависимости:**
```bash
npm install
```

**4. Настройте конфигурацию** (файл `.env`):
```
PORT=3000
SESSION_SECRET=придумайте-сложную-строку
DB_PATH=./db/voting.db
VOTING_START_TIME=18:00
VOTING_END_TIME=23:59
ADMIN_USERNAME=admin
ADMIN_PASSWORD=придумайте-надёжный-пароль
```

**5. Запустите сервер:**
```bash
npm start
```
Или с авто-перезагрузкой (для разработки):
```bash
npm run dev
```

**6. Откройте в браузере:**
- Сайт: http://localhost:3000
- Админка: http://localhost:3000/admin
- Вход в админку: логин `admin`, пароль из `.env` (по умолчанию `admin123`)

### Первый запуск
При первом запуске автоматически:
- Создаётся база данных SQLite
- Создаются все таблицы
- Заполняется меню блюд и напитков
- Создаётся администратор

## 3. Размещение в интернете

### Вариант A: Render (бесплатно, просто)

1. Зарегистрируйтесь на [render.com](https://render.com)
2. Нажмите **New + → Web Service**
3. Подключите GitHub-репозиторий
4. Настройки:
   - **Runtime**: Node
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
5. В разделе **Environment** добавьте переменные из `.env`
6. Нажмите **Create Web Service**

### Вариант B: Railway (бесплатно, просто)

1. Зарегистрируйтесь на [railway.app](https://railway.app)
2. Создайте новый проект → Deploy from GitHub repo
3. Добавьте переменные окружения как в `.env`

### Вариант C: VPS (Ubuntu)

```bash
# Установка Node.js
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs git

# Клонирование проекта
git clone https://github.com/your-repo/it-moscow-voting.git
cd it-moscow-voting

# Установка зависимостей
npm install --production

# Запуск через PM2 (менеджер процессов)
npm install -g pm2
pm2 start src/app.js --name it-moscow-voting
pm2 save
pm2 startup
```

**Настройка Nginx (прокси):**
```nginx
server {
    listen 80;
    server_name ваш-домен.ru;

    location / {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }
}
```

## 5. Идеи для развития

### 🔔 Уведомления в Telegram
- Бот, который напоминает студентам о голосовании в 18:00
- Админ получает уведомление о результатах с топ-блюдами
- Студент может подписаться на напоминание через бота

### 📅 Голосование по неделям
- Составлять недельное меню на основе голосов за понедельник
- Возможность голосовать сразу на несколько дней вперёд

### ⭐ Отзывы о блюдах
- После обеда студенты могут оценить блюдо от 1 до 5 звёзд
- Собирается статистика: какие блюда самые популярные и вкусные
- Администрация видит рейтинг каждого блюда

### 📊 Продвинутая аналитика
- Графики популярности блюд по дням недели
- Статистика по группам: какая группа активнее голосует
- Экспорт в PDF для отчётов

### 👤 Личный кабинет студента
- История своих голосов
- Возможность отменить голос (до закрытия)
- Настройка напоминаний (Telegram/email)

### 🎨 Улучшения дизайна
- Тёмная тема
- Анимация при загрузке результатов
- Drag-and-drop для перетаскивания блюд в избранное

## 🛡️ Безопасность

- **Пароли**: bcrypt с солью (10 раундов)
- **Сессии**: httpOnly cookie, secure в production
- **Rate limiting**: 200 запросов / 15 минут (общий), 20 попыток входа / 15 минут
- **SQL-инъекции**: все запросы параметризованные
- **XSS**: Helmet middleware, экранирование на фронтенде
- **Время**: проверяется на сервере, клиентское время не учитывается
- **Уникальность**: UNIQUE-ограничение в БД на (student_id, vote_date)
